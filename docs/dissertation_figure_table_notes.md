# Dissertation Figure and Table Notes

These notes are a practical guide for deciding which figures and tables to include in the final dissertation, which ones are better placed in the appendix, and what each output actually shows.

The goal is to keep the main text focused on the clearest and most defensible story:

- how the final sample was derived
- what the final sample looks like
- what the main age-group results were
- what those results mean in terms of segregation, within-network connectivity, and between-network connectivity

### Figure 2. Main Age Effects Summary

Recommended file:

- [main_age_effects_summary.png](/Users/lenkaokasova/Documents/GitHub/Dissertation-fMRI-Aging/fMRI-Network-Segregation-Aging/data/processed/analysis/dissertation_summary/figures/main_age_effects_summary.png)

What it shows:

- the older-versus-younger regression estimates for the main outcomes
- overall global segregation
- overall within-network connectivity
- overall between-network connectivity
- the seven network-specific segregation outcomes

How it was calculated:

- using the main age-group regression outputs
- model estimates compare older participants against younger participants
- confidence intervals are model-based intervals from the regression output
- `p` values come from permutation inference
- `q` values come from FDR correction

Why it should be in the main text:

- it is the cleanest single figure for the main findings
- it shows effect direction, approximate effect size, and inferential strength together
- it is more efficient than showing several separate results figures

Important note for the write-up:

- the confidence intervals are not permutation-based confidence intervals
- only the `p` values and `q` values are permutation/FDR based

### Figure 3. Within- and Between-Network Age Effects

Recommended file:

- [network_within_between_age_effects.png](/Users/lenkaokasova/Documents/GitHub/Dissertation-fMRI-Aging/fMRI-Network-Segregation-Aging/data/processed/analysis/within_between/figures/network_within_between_age_effects.png)

What it shows:

- whether older-versus-younger differences are coming more from:
- lower within-network connectivity
- higher between-network connectivity
- or both

How it was calculated:

- parcel-wise denoised time series were converted to subject-level connectivity matrices
- network-level within-network and between-network mean Fisher `z` connectivity values were then computed
- these values were modeled by age group at the network level

Why it should be in the main text:

- it adds interpretation beyond the simple statement that segregation differs by age
- it helps explain the mechanism of any segregation differences
- it links directly to the aging literature on reduced within-network coherence and increased cross-network mixing

## Short Recommended Final Set

If the dissertation needs to stay concise, the strongest final set is:

- `Figure 1`: sample flow
- `Table 1`: participant characteristics
- `Figure 2`: main age effects summary
- `Table 2`: main age effects results
- `Figure 3`: within- and between-network age effects

Then in the appendix:

- normative heatmap
- robustness figures
- balanced `11 x 11` sensitivity branch
- one atlas overlay example plus summary table
- one denoising QC example plus summary table
- permutation/FDR detail figure

This gives a coherent final structure:

- main text = focused, interpretable, defendable
- appendix = transparent, careful, methodologically complete
